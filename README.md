# File Processing Application (JavaFX)

A JavaFX-based desktop application for efficient file reading, text replacement using regular expressions, batch processing, and searching files in directories based on filename patterns.

## 🚀 Features

- 📂 Load and display text file contents.
- 🔍 Search and replace using regex patterns.
- 🧹 Batch process files with custom text processing (e.g., clean or summarize).
- 🗂️ Search for files in a directory using regex-based filename patterns.
- 📁 Select files and folders using FileChooser and DirectoryChooser dialogs.
- ✅ Supports modular processing via `TextProcessor` utility methods.
  

- 🔍 **Advanced Regex Operations**
  - Pattern matching with groups/captures
  - Find/replace with backreferences
  - Match highlighting in results

- 📁 **File Batch Processing**
  - Process multiple files with regex
  - Preserve directory structure
  - Large file support (>1GB)

- 📊 **Text Analysis**
  - Word frequency statistics
  - Email/URL extraction
  - Custom pattern analytics

## 🛠 Technologies Used

- Java 21+
- JavaFX 21
- Maven 
- Regex
- Lambda expressions and Stream API
